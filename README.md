# Programming Club: Innovators in Action 🚀

The official landing page for the **Programming Club of Royal Institute International School - Nugegoda**. This project is a highly interactive, visually striking, single-page web application designed to showcase the club's vision, core values, upcoming activities, and leadership team.

The website features a modern 3D Glassmorphism aesthetic, driven by interactive mouse-tracking effects, custom scroll animations, and a dynamic HTML5 Canvas particle network background.

---

## ✨ Features

### Interactive 3D Glassmorphism
Cards and panels tilt and react in 3D space based on mouse cursor movement, complete with dynamic lighting glares.

### Dynamic Particle Network
A custom HTML5 Canvas particle system running in the background, drawing connecting lines between nodes based on proximity.

### Fluid Blob Animations
CSS-animated gradient blobs that provide depth and a modern aesthetic to the dark UI.

### Scroll-Triggered Animations
Elements smoothly reveal themselves as the user scroll down the page using the Intersection Observer API.

### Fully Responsive
Seamlessly adapts to mobile, tablet, and desktop viewports with a custom mobile navigation menu.

### No Build Tools Required
Utilizes Tailwind CSS via CDN for rapid styling without the need for a complex Node.js build pipeline.

---

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure.
- **CSS3 / Tailwind CSS**: Core styling, fluid typography, and utility classes.
- **Vanilla JavaScript (ES6)**: DOM manipulation, 3D tilt physics, canvas particle rendering, and scroll observers.
- **Font Awesome (v6.4)**: Iconography used throughout the UI.
- **Google Fonts**:
  - Space Grotesk for striking headings.
  - Inter for clean, readable body text.
